Automatic end-of-day export

Files land in <folder>/<date>/<SYMBOL>_<bar>.<format> on the machine running Orazio. Orazio must be running at that time — if it isn't, the export runs as soon as it starts that day. NSE's closing auction runs to about 15:35, so bars after that arrive late.
